Concept

3つのこだわり

「ここなら任せられる」と言っていただける理由です。

01

原因から整える根本施術

痛い場所だけをもむのではなく、姿勢・骨盤・日常の動き方まで確認し、痛みの原因に働きかけます。再発しにくい体づくりが目標です。

02

完全予約制で待ち時間なし

ご予約のお時間に、お一人ずつ対応します。忙しい方の通院が続くように、施術時間と計画は最初に分かりやすくご説明します。

03

国家資格者がすべて担当

柔道整復師の国家資格を持つ施術者が、検査から施術、経過の確認まで一貫して担当。毎回同じ目で体の変化を見ていきます。

Symptoms

こんなお悩みに

ひとつでも当てはまったら、我慢せずにご相談ください。

✓

肩こり・首の痛み

デスクワークやスマホ姿勢からくる、重だるさや張り。

✓

腰痛・ぎっくり腰

朝起きるのがつらい慢性の腰痛から、急な痛みまで。

✓

膝の痛み

階段の上り下りや、歩き始めに感じる膝の違和感。

✓

頭痛・目の疲れ

首や肩の緊張からくる、繰り返す頭の重さ。

✓

姿勢のゆがみ・猫背

写真で気になる背中の丸さ、体のバランスの崩れ。

✓

産後の骨盤ケア

出産後の腰痛や体型の変化、育児での体の負担に。

✓

スポーツのケガ

捻挫・肉離れなど、競技復帰までの計画的なケア。

✓

交通事故後の不調

むちうちなど事故後の痛み。保険の手続きもご相談ください。

※ 症状によっては医療機関の受診をおすすめする場合があります。その際も遠慮なくご相談ください。
